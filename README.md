# Calculadora IPv4 - Frontend

Maqueta estática (HTML y CSS) de la interfaz de la calculadora web de direccionamiento IPv4 de Redes de Datos I, Universidad El Bosque, 2026-II.

**Cómo correrla:** abrir `app/index.html` en el navegador, y también `app/enlace-31.html`, `app/multicast-clase-d.html` y `app/error-validacion.html`. No hace falta servidor ni internet.

```
app/
├── index.html               resultado normal (192.168.1.100/24)
├── enlace-31.html           enlace punto a punto (10.0.0.0/31)
├── multicast-clase-d.html   multicast, clase D (224.0.0.1/24)
├── error-validacion.html    error de validación (máscara no contigua)
├── css/styles.css           hoja de estilos compartida
└── fuentes/                 Ranade (.otf) e IBM Plex Mono (.woff2)
```
