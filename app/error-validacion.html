Calculadora de direccionamiento IPv4

Ingresa una dirección con prefijo o con máscara decimal. Las dos formas dan el mismo resultado para la misma subred.

Entrada

Cuatro octetos de 0 a 255, por ejemplo 192.168.10.25
Por ejemplo 255.255.255.224
Error: la máscara no es contigua. Debe tener todos los unos seguidos y luego todos los ceros, por ejemplo 255.255.255.0.

Casos de prueba

Selecciona uno para cargarlo en el formulario.

Resultado

Todavía no hay resultado. Corrige la máscara y vuelve a calcular.

Se validan cuatro octetos enteros de 0 a 255, prefijos de 0 a 32 y máscaras con los unos contiguos. Cualquier otra entrada se rechaza con un mensaje que indica qué campo corregir.
